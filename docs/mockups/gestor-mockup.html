Gestió de punts i recompenses · Malgrat de Mar

Backoffice del gestor de la població (ajuntament o entitat gestora, per definir). Hi ha un únic gestor per població — Malgrat de Mar, Blanes i Lloret de Mar tenen el seu, cadascun només veu el propi. Té dues funcions: configurar les accions que atorguen punts als veïns i administrar el catàleg de recompenses bescanviables per punts. Comparteix el mateix shell que el backoffice del comerç (canvia el rol i la navegació). Web responsiva desktop + mòbil. Tokens KM0 reals · català.
